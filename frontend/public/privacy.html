Privacy Policy

Effective 7 November 2026

Verixa is a university project that scores the risk of GitHub pull requests. This page explains what personal data it stores, why, and how to remove it. We do not sell personal data or use it for advertising.

What we store

DataWhy it is needed
Account: name, email address and a salted hash of your passwordTo create your account and log you in. We cannot read your password.
GitHub: user ID, username, display name and encrypted access and refresh tokensTo sign you in with GitHub, list your repositories, manage the webhook and read pull requests.
Atlassian: encrypted access and refresh tokens, Jira site name and site IDTo list your Jira projects. We do not store your Atlassian profile or account ID.
Two-step verification: an encrypted secret and hashed recovery codesTo check your sign in codes, if you turn this on.
Project: repository name, Jira project, uploaded Playwright specs and Postman collectionTo run your workspace and Test Library. Do not put secrets or personal data in these files.
Pull request results: repository, number, title, link, author's GitHub username, commit ID, changed file counts and names, score, reasons, AI explanation and suggested test areasTo show the Risk Analysis screen.

The code changes in a pull request are read to work out its score, and are not saved in the database. Short parts of a result, such as file names and the start of an AI answer, can appear in the server's technical logs.

Cookies and browser storage

We use one login cookie, which lasts up to 14 days, and browser storage for your light or dark theme. We do not use advertising or tracking cookies.

Who receives data

Verixa uses these outside services to work:

  • GitHub and Atlassian: the accounts you choose to connect.
  • Neon: hosts the database.
  • AI model providers: currently Groq. OpenRouter or Google Gemini can be set up as backups. They receive the pull request title, file names and part of the code changes. Verixa replaces values that look like secrets before sending, but it cannot recognise every secret, so private code can still be included.
  • ngrok: carries traffic to the app when it runs through a tunnel.
  • Google Fonts: supplies the fonts on our pages, so Google can receive your IP address.

How long we keep it

We keep your data until you disconnect your project or delete your account. Technical logs have no automatic deletion date, and are cleared by the project team. An outside service may keep data under its own policy.

Your choices

  • Name: change it in your account settings.
  • Disconnect: removes the webhook, Test Library and pull request results for your project.
  • Delete account: removes your account, saved tokens, recovery codes and project data from the database. It does not revoke access on GitHub or Atlassian, which you can do in their settings.
  • Questions or a copy of your data: email us using the address below.

Security

Passwords are hashed with scrypt, and saved tokens and two-step secrets are encrypted. Verixa asks GitHub for the repo permission, which is broad: it allows reading and writing your repositories, although the agents only read them. No online service is perfectly secure, so please connect only repositories you are comfortable using with a student project.

Changes and contact

If this policy changes, we will update this page and its date. Contact: verixa.offical@gmail.com
